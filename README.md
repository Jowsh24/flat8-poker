# Flat 8 Poker

A practice No-Limit Texas Hold'em table for the flat 8 home game (10p/20p blinds, £10 buy-in, 7 players).

**Play:** https://jowsh24.github.io/flat8-poker/

- Pick who you are, then play **solo** against computer versions of everyone else, or **host / join a live table** with a 4-character code. The computer fills any empty seats.
- In solo, tap any player's seat to see just their cards.
- Your decisions are saved anonymously so the computer players can learn to play more like the real people.

Play money only.
